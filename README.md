# 📖 Overview

**AI Autonomous Creator** is an intelligent AI-powered platform designed to automate creative workflows using modern Artificial Intelligence technologies. It enables users to generate, manage, and enhance digital content with minimal manual effort through autonomous AI agents and smart automation.

The project focuses on making AI accessible for creators, developers, businesses, and innovators by providing an intuitive and scalable solution.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/ianuj-yadav/Ai-Autonomous-Creator.git
```

Move into project directory

```bash
cd Ai-Autonomous-Creator
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm start
```
